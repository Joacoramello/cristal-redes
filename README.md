# cristal-redes

Material de las redes de Química Cristal (Río Cuarto).

- `skills/`: las skills de redes (cristal-marca, cristal-plan, cristal-reel, etc.). La tarea semanal las lee desde acá.
- `media/AAAA-Wnn/`: placas de carruseles que publica Metricool.
- `videos/AAAA-Wnn/`: reels grabados, ya comprimidos, que publica Metricool.

Las skills están basadas en instagram-agent-skill de Jake Schincariol (MIT), portadas al español y a Química Cristal. Ver `LICENCIA.txt` en cada skill.
